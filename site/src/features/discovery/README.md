# Поиск

Фильтры и результаты публичных каталогов, включая организации и авторов.

`directory-server` — серверный вход для композиции каталогов.

Внутренние компоненты не являются публичным API. Маршруты остаются в App Router; сервисы, авторизация, доступ к данным и существующие правила предметной области сохраняются в прежних слоях. Границы импортов проверяются dependency-cruiser и тестами архитектуры.
| `discovery-stream-copy.ts` | util port `discovery-stream-copy` |
| `discovery-copy.ts` | util port `discovery-copy` |
| `discovery-stream-contract.ts` | util port `discovery-stream-contract` |
| `discover-query.ts` | util port `discover-query` |
