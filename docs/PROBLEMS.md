# Открытые проблемы

Здесь только проблемы, которые ещё нужно проверить или решить. Не добавляйте сюда историю завершённых изменений; она хранится в Git. Статус подтверждается конкретным запуском на конкретном коммите и среде.

## Зависимости

Регулярно проверять `pnpm audit` и обновлять зависимости небольшими группами с тестами и сборкой. В графе остаются устаревшие транзитивные пакеты `@esbuild-kit/core-utils` и `@esbuild-kit/esm-loader`: определить безопасный путь их замены. Vite ограничен версией 7.3.7 ради совместимости; при следующем обновлении инструментов пересмотреть это ограничение.

## Приёмка релиза

Локальная сборка и тесты не подтверждают готовность целевой инфраструктуры. Для кандидата нужны обязательные CI-проверки на точном SHA, браузерные сценарии и матрица целевых устройств, проверка доступности, реальные настройки почты и push, TLS, хранилище, наблюдаемость, проверка backup/restore и безопасного обновления существующей БД. Статус удалённого CI и его настройки защиты ветки нужно проверить отдельно.

## Доставка уведомлений

Исторически потерянные уведомления автоматически не восстанавливаются. Verification, reports, support, discussion, server-publication fanout и user-follow notices коммитят транзакционный источник (job или inbox) без Next.js `after()`; worker перепроверяет eligibility. Миграции 0083/0084 не заполняют доставку для старых комментариев/публикаций. Исчерпание повторов fanout (attempts = 5) требует устранения причины и адресного operator reset по [инструкции эксплуатации](OPERATIONS.md#recovering-report-inbox-delivery); внешняя push-доставка по-прежнему не exactly-once.

## Проверки и сопровождение

Тесты PostgreSQL внутри одного запуска используют общую БД и выполняются последовательно. Полный набор не запускать одновременно с тяжёлой сборкой на ограниченном хосте. Для локальных изменений выбирать связанные проверки; долгие сценарии оптимизировать по измеренным затратам, сохраняя проверки конкуренции и отката.

Dependency-cruiser пока не поддерживает API TypeScript 7: для анализа зависимостей типов ему отдельно установлен TypeScript 6. При поддержке TypeScript 7 в анализаторе удалить обходное решение; новые конструкции TypeScript 7 проверять отдельно.

## Production-сборка

Turbopack предупреждает о широком tracing для динамических путей storage и mail-secret. Тесты, документация и служебные файлы исключены из standalone-пакета; проверить более точную границу tracing без ослабления безопасного доступа к файлам.

## Размер модулей

Репозитории `community-reports.ts` и `builds.ts` объединяют много операций и затрудняют локальное изменение. Разделять по ответственностям вместе с соответствующими задачами, сохраняя транзакции, авторизацию и поведенческие тесты. Сам по себе размер файла не доказывает ошибку.
