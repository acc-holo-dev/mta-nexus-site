# Открытые проблемы

Здесь только проблемы, которые ещё нужно проверить или решить. Не добавляйте сюда историю завершённых изменений; она хранится в Git. Статус подтверждается конкретным запуском на конкретном коммите и среде.

## Зависимости

Регулярно проверять `pnpm audit` и обновлять зависимости небольшими группами с тестами и сборкой. В графе остаются устаревшие транзитивные пакеты `@esbuild-kit/core-utils` и `@esbuild-kit/esm-loader`: определить безопасный путь их замены. Vite ограничен версией 7.3.7 ради совместимости; при следующем обновлении инструментов пересмотреть это ограничение.

## Приёмка релиза

Локальная сборка и тесты не подтверждают готовность целевой инфраструктуры. Для кандидата нужны обязательные CI-проверки на точном SHA, браузерные сценарии и матрица целевых устройств, проверка доступности, реальные настройки почты и push, TLS, хранилище, наблюдаемость, проверка backup/restore и безопасного обновления существующей БД. Статус удалённого CI и его настройки защиты ветки нужно проверить отдельно.

## Границы авторизации и уведомлений

Закончить перенос изменяющих browser API-маршрутов с защиты только на Proxy на общий `withBrowserMutation`; проверять сессию и права внутри критических транзакций. Проверить гарантии доставки событий между транзакцией, уведомлением и worker; не считать best-effort события гарантированной очередью.

## Проверки и сопровождение

Тесты PostgreSQL используют общую БД и выполняются последовательно. При параллельной сборке один интеграционный тест превысил 30 секунд; отдельный повтор прошёл за 18 секунд. Устранить зависимость от перегрузки и измерить выполнение без ослабления проверок. Для локальной разработки выбирать связанные проверки; полный набор не отключать.

Линтер сообщает 37 предупреждений; устранить их по смыслу, без механического подавления. Dependency-cruiser пока не поддерживает API TypeScript 7: для анализа зависимостей типов ему отдельно установлен TypeScript 6. При поддержке TypeScript 7 в анализаторе удалить обходное решение; новые конструкции TypeScript 7 проверять отдельно.

## Размер модулей

Репозитории `community-reports.ts`, `builds.ts` и `library-collections.ts` объединяют много операций и затрудняют локальное изменение. Разделять по ответственностям вместе с соответствующими задачами, сохраняя транзакции, авторизацию и поведенческие тесты. Сам по себе размер файла не доказывает ошибку.

## Документация

Часть предметных глав handbook содержит смешанные утверждённые решения, черновые и исторические формулировки. Перед изменением соответствующей области сверять [Decision Register](handbook/13-DECISION-REGISTER.md) и код. Сократить и привести главы к единому формату, сохраняя решения владельца; проверить относительные ссылки и якоря. Исторические runbook-записи в Operations требуют отдельной очистки без потери реальных процедур восстановления.
