## Цель

MTA NEXUS объединяет публичные серверы Multi Theft Auto, ресурсы, сообщество и marketplace вокруг общей идентичности и доказуемого доверия. Один человек может играть, публиковать, владеть сервером и состоять в org; onboarding не закрепляет его в одном разделе навсегда.

Ценность ближайшей **бесплатной beta** — законченные пути: найти ресурс или сервер → понять автора и ограничения → получить доступ → вернуться → задать вопрос и увидеть ответ. Владелец проекта должен безопасно обновлять сервис и восстанавливать данные.

## Акторы

| Для кого              | Польза                                                                                                          |
| --------------------- | --------------------------------------------------------------------------------------------------------------- |
| Игрок                 | Найти действующий сервер, понять состояние, следить за обновлениями, участвовать в сообществе                   |
| Владелец сервера      | Подтвердить контроль, управлять страницей и командой, публиковать события, находить ресурсы                     |
| Автор ресурса         | Показать версии, происхождение, зависимости и проверки; распространять работу безопасно                         |
| Команда / org         | Управлять общими объектами и разрешениями без передачи личного аккаунта                                         |
| Покупатель и продавец | Понятные условия лицензии, доставки, обновлений, поддержки и споров (**цель**; платежи в free beta не включены) |
| Staff                 | Обрабатывать обращения по полномочиям, сохранять доказательства, объяснять решения и апелляции                  |

## Happy path (free beta)

| Путь                             | Минимальное завершение                                                                            |
| -------------------------------- | ------------------------------------------------------------------------------------------------- |
| Гость → ресурс → вход            | Объект и безопасное намерение сохранены; после входа понятен следующий шаг                        |
| Каталог → карточка               | Автор, описание, доступность и источник показателей; фильтры сохраняют смысл URL                  |
| Получение → библиотека → версия  | Понятна выдаваемая сборка; latest и выбранная версия различаются                                  |
| Публикация → модерация → доступ  | Автор видит требования; публична только допустимая сборка                                         |
| Обсуждение → ответ → уведомление | Черновик/контекст сохранены; unread фильтрует реальный список                                     |
| Сервер → профиль → клиент        | Действие в ожидаемый контекст; connect intent ≠ доказанное участие                                |
| Support/staff → решение          | Контекст сохранён, полномочия на сервере, аудит                                                   |
| Релиз сайта → среда              | Exact digest, проверенный комплект, recovery plan                                                 |

Подробности сценариев — [FLOWS](FLOWS.md); UI — [UX-CONTRACT](UX-CONTRACT.md); карточки — `planning/tasks.json`.

## Ошибки и лимиты (срез)

| Ситуация                         | Ожидание                                                           |
| -------------------------------- | ------------------------------------------------------------------ |
| Истёкшая ссылка / удалённый объект | Не «пустая выдача»; явный отказ или recovery                     |
| Ошибка загрузки каталога         | ≠ пустой список ≠ неизвестный online                               |
| Quarantine / отзыв / scan fail   | Публичная выдача блокируется; автор видит причину в допустимых границах |
| Ошибка загрузки ≠ пусто          | Различать zero / unknown / error                                   |
| Technical PASS CI                | ≠ deploy authorization / production ready                          |

## Current runtime (факт)

- Код распространяет **бесплатные** ресурсы; реальные платежи, выплаты и production DRM **не** включены.
- Платный marketplace, подписки и seller-opt-in DRM — утверждённое направление ([COMMERCIAL-FUTURE](COMMERCIAL-FUTURE.md)), не runtime beta.
- Все публичные серверы из master list видимы независимо от регистрации владельца. Claim открывает управление и доказывает контроль, но **не** условие появления в каталоге. Live-данные не подменяются редактором страницы ([SERVERS-ORGS](SERVERS-ORGS.md)).

## Home / Discover

Общая Home для гостя и аккаунта: конечные секции с дальнейшим переходом, без обязательного dashboard redirect. Гость понимает площадку и читает публичное; защита действия не превращает всё знакомство в registration wall. Personal changes summary — proposal модуля, не новое имя главной ([UX-CONTRACT](UX-CONTRACT.md)).

## Принципы

- Ценность — в связанных сценариях, не в числе экранов.
- Реальные данные и происхождение показателей; заглушки не выдаются за результат.
- Проверка артефакта, право доступа и репутация — разные смыслы; платёж не покупает доверие.
- Удержание — на пользе ([RETENTION-PLAN](RETENTION-PLAN.md)); North Star / слоган не блокируют обычную работу.

## Что не обещать как готовое

Личные сообщения, полноценные groups/clans, календарный сервис, versioned server pack, 3D preview и in-game проба — будущие направления ([COMMUNITY](COMMUNITY.md), [RESOURCES](RESOURCES.md), [SERVER-PACK-SPEC](SERVER-PACK-SPEC.md)).

Реклама: staff-managed pilot (F5) vs self-service/checkout/payouts/DRM (F6). Органика, verification и безопасность файла не продаются скрытно.

Нет измеренного % удержания, подтверждённой ёмкости production-host или календарной даты выпуска только из наличия документов.
