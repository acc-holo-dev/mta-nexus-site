## Сохраняемые основы

MTA NEXUS — единая площадка сообщества; RU/EN, реальные данные, privacy by default. Коммерческая цель сохраняется, но ближайшая бесплатная beta не получает платежи автоматически. Решения о необязательной 2FA, ограничениях публичной выдачи ресурсов, правах staff, типах лицензий и приватности не меняются вследствие сокращения документации. Точные исключения и действующие статусы берутся из исходных строк реестра, а не восстанавливаются по памяти.

## Согласование AI-007

Историческая формулировка AI-007 («AI может commit/push directly to `main`») расходилась с корневым [AGENTS.md](../AGENTS.md): отправка в GitHub требует прямого указания владельца. В DOC-02 ID **AI-007** сохранён; действующая норма в реестре обновлена и ссылается на AGENTS. Прежняя редакция остаётся в Git. Push, release и наличие workflow сами по себе не разрешают production deploy, разрушительные операции с данными или реальные платежи.

## Как менять решение

Используйте стабильный ID и независимые статусы решения, реализации и включения. Новый вывод содержит источник, причину, последствия и затронутые задачи. Старый ID не переиспользуется для другого смысла. Изменение решения владельца требует его нового указания; обратимая техническая реализация внутри разрешённой задачи может быть выбрана агентом самостоятельно.
