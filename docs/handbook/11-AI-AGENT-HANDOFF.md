# Инструкция разработчику

Основные правила находятся в [AGENTS.md](../../AGENTS.md). Начните с текущей задачи и её кода; используйте [карту областей](15-AI-CONTEXT-INDEX.md) и [Decision Register](13-DECISION-REGISTER.md) для необходимых решений. Действующие инструкции владельца имеют приоритет. Код и тесты описывают фактическое поведение, не превращайте целевой функционал в заявленный текущий.

Сохраняйте защиту данных, проверку прав, безопасную публикацию ресурсов и честный статус проверок. Не копируйте историю разработки в документацию. Обновляйте соответствующие архитектурные правила и открытые проблемы вместе с изменением поведения.
