# Единый интерфейс

Используйте `packages/ui`, семантические токены `apps/web/src/app/globals.css`, существующую локализацию и соседние компоненты. Новое визуальное решение должно решать конкретную задачу; отдельная система компонентов, цветов или взаимодействий без необходимости не создаётся.

## Общий контракт

- RU/EN равноправны: интерфейс, ошибки, даты, числа, доступные подписи и состояния локализованы.
- Светлая/тёмная темы, desktop/mobile, клавиатура, focus management, reduced motion и читаемый contrast проверяются вместе с изменением.
- Интерактивный сценарий имеет loading, empty, error и подтверждённый success. Сохраните введённые данные и понятный повтор после ошибки.
- Успех показывается после ответа сервера для ожидаемого объекта и состояния. Optimistic UI не превращает отказ в видимый успех.
- Семантические элементы, подписи, skip-to-content, диалоги и восстановление фокуса доступны с клавиатуры. Автоматический axe не заменяет проверку реального сценария.
- Серверный production error показывает correlation/request ID для поддержки, без stack trace и секретов. Offline явно видим и блокирует чувствительные изменения.
- Пустой экран объясняет состояние и следующий доступный шаг. Не заполняйте его вымышленными метриками, отзывами или успешными результатами.

## Навигация и формы

Целевая Home едина для гостя и аккаунта: поиск, обзор экосистемы и конечные разделы с «Показать больше». После входа добавляются персональные модули; принудительный переход в dashboard не нужен. Infinite scroll допускается в отдельном Community Feed. Discover разделяет типы сущностей по вкладкам/разделам.

Workspace — одна адаптивная поверхность доступных возможностей. Верхняя навигация охватывает Home, Servers, Market, Community, Messages, Notifications, Workspace/Profile; Discover видим. Onboarding можно пропустить и изменить позже; он не фиксирует роль навсегда. Command palette и навигация через изучение команд не требуются.

Большие формы публикации — полноэкранный wizard с сохранением контекста. Purchase detail использует вкладки. Высокоопасное staff-действие показывает impact preview. Поиск допускает явные фильтры и доступный выбор; клиент не заменяет серверную фильтрацию приватных данных.

## Доверие и персонализация

Open/Closed Source, DRM при применимости, лицензия, цена, автор, проверка, версия и условия доставки показываются понятными словами. Verification объясняет доказанное свойство. Sponsored-размещение маркируется и не подделывает органический рейтинг.

Публичный профиль использует безопасные поля, immutable ID и при наличии права vanity username. Activity — timeline/feed; Trust/Reputation — отдельная поверхность доказуемой истории. Настройка профиля или серверной страницы не может подделать trust-индикаторы. Безопасный редактор серверной страницы имеет desktop/mobile preview.

Персонализацию можно полностью выключить, сохранив нейтральные recent/trending/filter-based поверхности. Отдельная сложная система micro-feedback не является обязательной.
